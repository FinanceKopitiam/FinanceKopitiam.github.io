Finance Kopitiam Analytics is a private desktop application used by the Finance Kopitiam creator to review their own YouTube channel and inform future educational videos about money.

Finance Kopitiam explores budgeting, saving, debt, investing and other financial topics. This website explains the companion application's purpose, permissions and data handling.

Read the privacy policyVisit Finance Kopitiam on YouTube

What the application does

With the creator's permission, the application checks channel identity, reads supported public video information and requests aggregate channel performance reports, such as views, watch time and average view duration. These reports help the creator evaluate their content.

An optional, separately approved request can list available YouTube Reporting report types. Missing or delayed data is kept unknown.

Why Google permission is needed

The application uses YouTube API Services. Read-only YouTube permission identifies the authorised channel and reads supported video data. Read-only Analytics permission retrieves the channel owner's reports, which are not available from a public video page.

Google handles sign-in and consent in the system browser. The application does not ask for a Google password.

For the channel creator's own use. This is an information website, not a public analytics service. There is no website login or visitor account. The desktop connection currently operates under human supervision.

Read access, with human control

The current connector requests only youtube.readonly and yt-analytics.readonly. It does not upload videos, edit channel settings, moderate comments or request monetary reports. Script approval, video review and any publishing decision remain separate creator actions.

Authorised reports stay in the creator's protected local storage. They are not published on this website or committed to its public repository. Read the privacy policy for retention, deletion and revocation details, and the terms of use before using the application.

Contact

For questions about Finance Kopitiam Analytics or its data practices, contact financekopitiam.official@gmail.com. Please do not include passwords, tokens or authorisation codes.
