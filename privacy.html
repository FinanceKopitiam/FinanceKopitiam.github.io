Privacy policy

Effective date: 18 October 2026

This policy describes the Finance Kopitiam Analytics desktop application and this information website. The application is operated by the Finance Kopitiam channel creator for their own channel. It is not offered as a multi-user service.

Information the application accesses

The application uses YouTube API Services. It requests only the following Google permissions:

  • https://www.googleapis.com/auth/youtube.readonly — to check the authorised YouTube channel and read supported channel or public-video information.
  • https://www.googleapis.com/auth/yt-analytics.readonly — to read aggregate performance reports for that channel.

Information can include the channel identifier, public video identifiers and titles, available public statistics, reporting dates, views, estimated minutes watched and average view duration. An optional approved Reporting catalogue request can return report-type identifiers and availability. The current connection does not collect individual viewer identities, payment information, passwords, private messages or monetary Analytics reports.

Google supplies access and refresh tokens after the operator consents. These tokens allow the application to make approved requests and refresh access without asking for a password. They are different from the channel's analytics data.

Purpose and sharing

The creator uses the information to verify the correct channel, review their content's performance and inform future editorial decisions. The application makes requests to Google's official services. It does not sell Google user data, use it for advertising, or publish private channel reports.

In the current supervised connector, raw API responses and private metric values are not sent to AI model services. Redacted connection outcomes and necessary diagnostic metadata may be reviewed with the creator's development assistant; credentials and raw reports are excluded. Any future change to data use or sharing requires updated disclosures and appropriate consent before it is introduced. Google user data is not used to train general-purpose AI models.

Our handling of Google API information follows the Google API Services User Data Policy, including its Limited Use requirements. Google's own handling is described in the Google Privacy Policy.

Local storage and security

Imported OAuth client information and tokens are encrypted using Windows user-account protection. Normalised API observations are stored separately in access-restricted local folders outside the public website, source repository and ordinary project backups. This is not a claim that every report file is encrypted or that an unrestricted program running under the same Windows account is isolated from it.

Operational records retain limited information such as request times, method names, quota accounting, outcomes and references. They omit raw API payloads, private metric values and credentials. The application suppresses HTTP debugging and uses encrypted HTTPS connections to Google.

Retention and deletion

API observations and their indexed review copies expire within 30 days of retrieval. Expired data is denied on access. The local maintenance function removes indexed copies; the operator must run it by the applicable deadline. This supervised setup does not have an active unattended cleanup service, and a switched-off PC cannot perform deletion. Data must not be copied into ordinary backups or permanent review packets.

Tokens are kept while access is needed and authorised. The operator can remove the local authorisation and its associated observations using the application's local removal function. A detected revoked or invalid grant stops access and triggers local cleanup; unresolved deletion blocks further collection. The operator must complete requested local deletion promptly, with a seven-calendar-day completion deadline for the application's revocation/deletion workflow.

Revoke access or request help

You can revoke this application's Google access through Google Account permissions. Select the application's entry and follow Google's removal instructions. This does not change or delete the videos on YouTube.

Removing permission at Google does not instantly erase files on an offline computer. The creator should also use the local removal function or request deletion through the support contact below. Removing only a local token does not itself revoke the grant at Google; use both steps when disconnecting completely.

For privacy questions or deletion requests, contact financekopitiam.official@gmail.com. Do not send passwords, tokens or authorisation codes in a support request.

Visitors to this website

These static pages contain no account form, advertising, tracking scripts, analytics tags, embedded videos or application cookies. They do not request Google authorisation or receive channel reports.

This website is hosted on GitHub Pages. GitHub states that it logs visitors' IP addresses for security purposes, including visits by people who are not signed in. See GitHub's Privacy Statement. Following an external link takes you to a separate provider governed by its own policies.

Changes to this policy

The creator will update this policy before changing the application's data practices. Any materially different access or use requires the appropriate permission. This policy describes the current supervised connector; it does not claim that future automation has been enabled.
